Задача 1. Зафиксировать стабильную точку
Цель: создать commit перед любыми изменениями.

Формулировка для агента:

Invariant:
Текущее состояние репозитория должно быть сохранено как отдельная стабильная точка до любых изменений под публикацию.

Scope:

Проверить git status
Зафиксировать все текущие изменения
Создать commit с нейтральным сообщением о baseline перед GitHub publication prep
Вернуть hash коммита и краткий summary what was committed

Out of scope:

Любые изменения файлов
Форматирование
Удаления
Документация

Artifacts:

git status до коммита
commit hash
git status после коммита

DoD:

Working tree clean
Есть новый commit
Возвращён точный commit hash
